# OpenSeat

**You never know who you'll meet.**

Good places. New faces. OpenSeat is an app for meeting new people over food and drinks at real places. Find a table at a local restaurant, claim a seat, show up. Or start your own table and let others join. No swiping, no profiles to browse: just real people getting together in real places.

- Website: [openseat.ca](https://openseat.ca)
- Web app (in active development): [app.openseat.ca](https://app.openseat.ca)
